# Cubic Hurdle
Final project coded in Unity for a school game design project. Yes, this is literally just 3D Geometry Dash. You can try out the game [here](https://lasokar.github.io/Cubic-Hurdle/).
### Controls:

- Click to Jump (No, space bar doesn't work)
- A and D to turn around
- W to flip gravity
- S to unflip gravity
